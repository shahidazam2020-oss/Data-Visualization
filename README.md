# 📊 Data Visualization & Data Analysis Projects

Welcome to my **Data Visualization Repository**.

This repository contains a collection of academic and practical projects developed while working with **Python, data analysis, data preprocessing, visualization, and machine learning**. The projects cover different real-world datasets and demonstrate how data can be cleaned, explored, visualized, and used to generate meaningful insights.

My goal with these projects is to build practical experience in turning raw data into understandable information through effective analysis and visualization.
